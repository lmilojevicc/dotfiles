# Context usage command

Local port of [`/context` from pi-cc-extensions v0.9.5](https://github.com/minuque/pi-cc-extensions/blob/v0.9.5/extensions/feature/context.ts). See [LICENSE](LICENSE) for upstream MIT copyright and license. Only the command and the two small display/mouse helpers it uses are included; no other upstream UI features or configuration are installed.

`/context` shows an estimated breakdown of system prompt, memory, skills, tool definitions, tool results, conversation context, other usage, and free space. In the TUI, select a category with arrow keys or mouse and press Enter/click to open a second, scrollable menu. Choose an item to preview it. Esc goes from preview to submenu to the unchanged home panel, then closes. j/k, gg/G, Ctrl-d/u and mouse navigation work in menus; h/q go back, and l/Enter open the selected item. Previews support j/k, gg/G and Ctrl-d/u for scrolling. The interactive dialog is available only in the TUI. In other modes the command calls Pi's notification API, which some hosts do not display or serialize; do not rely on `/context` for non-TUI output. Category token counts are estimates based on content, reconciled with available context usage, not provider-reported per-category accounting.

Pi discovers `index.ts` through the extension directory symlink. Restart Pi after adding the extension. Run `npm test` in this directory to test the command and dialog without making a provider request.

Submenu figures are local estimates (tokens, percent of context window, percent of parent category), not provider accounting for individual items. Entries are always sorted by their share of the category, largest first, with ties keeping their source order, so the biggest consumers are visible without scrolling; zero-token sources such as an unloaded `SKILL.md` fall to the bottom. If raw leaf estimates exceed a reconciled parent (notably tool results or conversation after usage capping), leaf counts are scaled proportionally to that parent's displayed total with cumulative integer rounding; the displayed percentages use those scaled counts. If leaves estimate less than their parent, the difference remains unattributed rather than being invented for an item. Raw leaf content is unchanged and long raw lines wrap for vertical inspection. The system prompt leaf shows the complete prompt, including embedded memory/skills, while its token estimate is only the unattributed remainder. Skill advertisements are marked as prompt text; a readable on-disk `SKILL.md` is separately labeled **NOT LOADED** and counted as zero, because its file contents are not automatically in context. Tool definitions show local registered name/description/parameters, not an exact provider schema. Unattributed provider usage remains in the home-panel “Other” category rather than being assigned to an item.
