# Context usage command

Local port of [`/context` from pi-cc-extensions v0.9.5](https://github.com/minuque/pi-cc-extensions/blob/v0.9.5/extensions/feature/context.ts). See [LICENSE](LICENSE) for upstream MIT copyright and license.

`/context` is a hierarchical TUI inspector: category → individual item → raw local source. Categories show estimated tokens and percentages of the context window and total used; items show percentages of their category as well. The command reconciles category estimates with reported overall usage and shows remaining **Other (unattributed)** and free space. Projected conversation and tool-result messages can be inspected individually; where available, Pi's session projection applies compaction and context edits first. Older hosts fall back to compaction-aware raw entries, which do not reflect context edits and may include omitted or pre-replacement content; neither path represents the provider wire payload. The system-prompt category contains unassigned assembled prompt spans, including shared skill instructions/wrappers; each memory item includes its project-instructions wrapper, and each skill item contains only its XML advertisement in the assembled prompt. An optional child row for each advertised skill reads the full on-disk SKILL.md and is explicitly marked **SOURCE — NOT LOADED** (zero prompt tokens). Tools display the registered active name, description and parameter schema, **not** a claim about provider wire serialization. Forced/modified prompts may prevent individual memory or skill attribution; no unavailable payload is invented for Other or free space.

Token figures are rough character-based estimates, not provider counts per item. Context usage may differ from accessible session entries. Reconciliation may reduce the conversation/results category totals; individual item figures remain raw local estimates. Unknown context windows display `n/a` percentages and unknown free capacity. The raw preview retains whitespace and markup instead of rendering Markdown; tabs are expanded to two spaces for terminal display. Source text can differ from what the model sees when loaded later.

Navigate lists with `j/k` or arrows; `gg`/`g` and `G` go to top/bottom, Ctrl-d/u move half a page, PgUp/PgDn move a page. `l`/Right/Enter or click drills in; `h`/Left/Esc backs out, `q` closes. Mouse wheel and preview scrollbars work in fullscreen too. In non-TUI modes the command uses Pi's notification API, which some hosts do not display or serialize.

Pi discovers `index.ts` through the extension directory symlink. Restart Pi after adding the extension. From the worktree root run `npm test --prefix pi/extensions/context` to test without a provider request.
